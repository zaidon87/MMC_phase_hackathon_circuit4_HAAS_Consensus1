# Source Code

This folder contains reviewable source extracted or derived from the Simulink model.

## Layout

```text
src/
├── matlab/
│   ├── controllers/
│   ├── utils/
│   ├── config/
│   ├── scripts/
│   └── tests/
└── embedded/
    ├── include/
    └── src/
```

The MATLAB files are the primary research-control source. The C files are only candidates for later embedded migration.
